Methodology

Walk-forward folds: Per league, DC and ML are retrained on all prior seasons for each test season. No future data used at prediction time. Rolling features use a 1-match lag throughout. Bets from all leagues are merged chronologically and staked from a single shared bankroll.

Value bet threshold: Flagged when adjusted edge is 3% or more (after 6pp home-win penalty compensating for DC home bias). Best odds taken across: Bet365, Betfred, BetMGM, Betvictor, Bet&Win, Coral, Ladbrokes, Pinnacle, Betfair Exch.

Quarter Kelly: f = (p x d - 1) / (d - 1), stake = (f / 4) x bankroll, capped at 5% of current bankroll per bet.

Flat stake: GBP1 per bet (fixed).
